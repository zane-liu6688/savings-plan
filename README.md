# 攒钱计划 🐱💴

一个为国内用户做的**个人攒钱进度 App**（React Native + Expo）。填进工资和开销，它告诉你：**今天还能自由花多少钱**、**每个月能攒多少**、**到哪一年能攒够目标**。

> 数据存在手机本地（AsyncStorage），不联网也能用；需要多台手机共享时，可选登录云同步。

## 🌐 网页版（免装 App，推荐）

**https://zane-liu6688.github.io/savings-plan/**

手机浏览器直接打开就能用（iPhone / 安卓 / 电脑都行），可「添加到主屏幕」当 App 用。功能与安卓版一致，数据存本机浏览器，并支持导出/导入备份。

网页版云同步用 **GitHub 私有仓库**（浏览器跨域限制导致无法直连坚果云）：
1. 自己建一个**私有**仓库（例如 `your-name/savings-data`）
2. 生成 fine-grained token：权限只勾该仓库的 **Contents: Read and write**
3. 网页「设置 → 云同步」填仓库名 + 令牌 → 上传 / 恢复

> 本仓库**不包含任何真实账号、密钥或网盘密码**，所有云服务都需要使用者自己填。

## 功能

| 页面 | 作用 |
|---|---|
| 📊 看板 | 今日可自由支配额度、每天/每周/每月能攒多少、年份存款投影、目标达标判断 |
| 💰 收入 | 月薪 / 日薪多份叠加，自动算五险一金、专项附加扣除、中国个税、每月到手 |
| 🧾 扣除 | 五险一金（手填或按 10.5% 自动估算）+ 6 类专项附加扣除一键添加 |
| 🏠 生活 | 每月固定生活开销明细 + 工作工具/设备成本按天分摊 |
| 🛒 大件 | 一次性大额消费按天摊进每日成本 |
| ⚙️ 设置 | 攒钱总目标、年份管理、备份导入导出、云同步 |

## 税费口径：**只做参考，不参与计算**

税收政策经常变，网上查到的税率也不一定适用于你本人，所以 App **不会自动扣税**。它只按公开税率给你一个参考值，让你心里有数：

```
应纳税所得额 = 全年收入 − 60000（基本减除费用） − 五险一金 − 专项附加扣除
参考个税 = 应纳税所得额 × 税率 − 速算扣除数（3%/10%/20%/25%/30%/35%/45% 七级）
```

**收入按税前全额进入攒钱计算**。你实际交了多少税、多少社保，自己到「生活」页加一项开销（例如「交个税 500」「社保 840」）就行——这样算出来的才是你真实的账。

专项附加扣除按国家标准预填：住房租金 1500、房贷利息 1000、子女教育 2000、赡养老人 3000、继续教育 400、婴幼儿照护 2000（元/月），可自行修改或新增。

## 云同步（可选，两种任选）

### 方案一：坚果云 WebDAV（国内免费，推荐）

免费额度长期够用（每月 1GB 上传，账本文件只有几十 KB），不用备案、不用服务器。

1. 注册 [坚果云](https://www.jianguoyun.com/)
2. 网页版 → 账户信息 → 安全选项 → **添加应用**，得到一个「应用密码」（不是登录密码）
3. App 设置页 → 坚果云同步 → 填 WebDAV 地址（默认 `https://dav.jianguoyun.com/dav/我的坚果云/`）、邮箱、应用密码
4. 点「测试连接」→「上传到坚果云」；换手机后点「从坚果云恢复」

> 坚果云 `/dav/` 根目录不允许直接写文件，所以地址必须带「我的坚果云」目录；代码里对直接填 `/dav/` 的情况会自动补全一次。

同步文件是网盘根目录的 `cunqian-backup.json`，坚果云自带历史版本，误覆盖也能找回。

### 方案二：Supabase（备用，需自备项目）

本仓库不内置任何 Supabase 项目。想用的话：自己免费注册一个项目 → 在 SQL Editor 执行 [`src/sync/schema.sql`](src/sync/schema.sql)（建 `app_state_cn` 表 + 行级权限）→ 在 App 设置页填入你自己项目的 URL / publishable key。
